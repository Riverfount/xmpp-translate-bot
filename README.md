# xmpp-translate-bot

Bot de tradução para salas XMPP (MUC), usando LibreTranslate self-hosted como
backend de detecção de idioma e tradução.

O projeto está sendo construído seguindo um plano de implementação faseado
derivado da especificação técnica do produto (§16).

## Status

Em desenvolvimento — Fase 0 (bootstrap do repositório).
